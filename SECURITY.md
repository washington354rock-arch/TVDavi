# Política de Segurança / Security Policy

## Versões Suportadas / Supported Versions
Mantemos correções de segurança apenas para a versão mais recente do projeto.

| Versão / Version | Suporte / Supported |
| ---------------- | ------------------- |
| latest           | ✅                  |
| older            | ❌                  |

---

## Reportando Vulnerabilidades / Reporting Vulnerabilities

### Português
Se você encontrar uma vulnerabilidade de segurança neste projeto:
- **Não abra uma issue pública** com detalhes sensíveis.
- Envie um e-mail para: [seu-email@dominio.com]  
- Inclua o máximo de detalhes possível (passos para reproduzir, versão afetada, impacto potencial).
- Nós responderemos em até 48 horas e informaremos o prazo para correção.

### English
If you discover a security vulnerability in this project:
- **Do not open a public issue** with sensitive details.
- Please email: [your-email@domain.com]  
- Include as much detail as possible (steps to reproduce, affected version, potential impact).
- We will acknowledge receipt within 48 hours and provide a timeline for fixing the issue.

---

## Divulgação Responsável / Responsible Disclosure
Pedimos que:
- Nos dê tempo razoável para investigar e corrigir o problema antes da divulgação pública.  
- Evite explorar a vulnerabilidade.  
- Trabalhe conosco para garantir que os usuários estejam protegidos.  

We kindly ask that you:
- Give us reasonable time to investigate and fix the issue before public disclosure.  
- Avoid exploiting the vulnerability.  
- Work with us to ensure users are protected.
